## About me

I'm a Computer Engineering student at UPM and a student at 42Madrid, where I learn by building real projects from scratch — no teachers, strict clean code standards, and peer-to-peer evaluation.

I'm comfortable working at both low level (C, memory management, processes) and full stack web development. I like understanding how things work under the hood before using them.

- 🏫 Double track: traditional university + 42 methodology (peer-to-peer, project-driven)
